## 💭 Thought Process

Most people start learning AI by watching hours of theory.
I decided to start by building something real on Day 1 itself.

The idea was simple:
- Take user input from the terminal
- Send it to a real AI model via API
- Get a response back and print it

No UI. No database. No complexity.
Just the raw, fundamental building block of every AI application.

---

## 🛠️ What This Project Does

A terminal-based conversational AI chatbot that:
- Takes your question as input
- Sends it to the LLaMA 3.3 model via Groq API
- Prints the AI's response instantly
- Keeps running until you type `quit`

## 🚀 How to Run

1. Clone the repository
```bash
   git clone https://github.com/PrashikSawant/hello-ai-world.git
   cd hello-ai-world
```

2. Install dependencies
```bash
   pip install groq python-dotenv
```

3. Create a `.env` file and add your Groq API key

4. Run the chatbot
```bash
   python main.py
```
